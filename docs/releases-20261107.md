# ADC release — 2026-11-07

Android 0.2.8 (versionCode 14), CLI/Connector 0.1.9 and SDK 0.2.5.

## 中文

- 修复截图取帧队列、静止画面时间门槛及停止释放行为；无合格帧时在已有共享会话上有限恢复一次。输出保留等待帧、编码与恢复次数。
- 统一完整屏幕坐标，修复底部控件超出手势校验范围的问题。
- 支持可选 JPEG 截图；默认继续为无损 PNG。
- 手机与服务端协商在取任务时合并确认，减少一次请求；旧服务保留独立确认。
- 托管和本地 MCP 的截图及已完成异步结果直接交付图片内容块，保留元数据；artifact 资源读取复用当前账户、授权和任务可见性检查。
- Android 保持测试渠道、非强制更新，沿用现有签名证书。覆盖更新保留配对；重启后的屏幕共享仍须设备所有者授权。用户接管与控制会话到期继续生效。

本次不把实验执行器中的 H20 自主探索设为默认能力。设备取帧耗时不包含公网传输或主模型耗时；完整四层耗时尚未统一采集。

## English

- Repairs screenshot frame ownership, static-screen timing and stop/release behavior, with one bounded consumer-Surface recovery on the existing authorized display.
- Uses full-screen coordinates for bottom-edge gestures.
- Adds optional JPEG capture while retaining PNG as the default.
- Negotiates inline dispatch acknowledgement, preserving the separate ACK path for older services.
- Delivers MCP image content for screenshots and completed asynchronous results, retaining metadata. Hosted and local resource reads use the caller's current artifact authorization.
- Android remains an optional testing-channel update signed with the existing certificate. Pairing survives in-place updates; screen-sharing consent remains under the device owner's control. User takeover and lease expiry remain enforced.

Frame timings exclude public-network transfer and the main model. Experimental H20 exploration is not enabled as a default feature.
